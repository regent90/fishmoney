原始碼

進貨 NT$25蝦皮賣 NT$1200

代儲貨源研究：16688 上的 Google AI Pro 啟動連結，拿到手只有 1 小時有效。

結論

貨源可行，技術對接已打通，但還沒用真錢下過單。

16688 平台上的 Google AI Pro（Gemini）18 個月啟動連結，實測進貨成本約 ¥5.55（約 NT$25）；台灣蝦皮同類商品約 NT$1200。

已確認
16688 開放 API 可以詢價、下單、查單、投訴；我們寫的客戶端已用真憑證通過簽章驗證，詢價成功。
最大不確定
所有賣家都沒說連結來源；連結 1 小時內不用就過期、無售後；福利之後會不會被 Google 或 Jio 收回，沒有官方條款可查。
還缺的
運營錢包是 0，尚未實際購買一份走完「下單、啟動、追蹤」流程。

詢價、下單、查單、投訴。從運營錢包付款，回傳連結（卡密）。客戶端已完成，簽章通過。

最後，客人付款才下單

這一段還沒做：轉接層與店面。連結 1 小時內不用就過期，不能囤貨，所以客人付款後才即時向 16688 下單，再交付連結。客人啟動時可能要切換網路地區，收款方式待決定。

技術對接

16688 的開放 API 已能完成詢價、下單、查單、投訴。

我們寫的客戶端用真憑證詢價成功，簽章驗證通過。前端網站先不談，只管貨源。

端點用途花錢嗎
purchase/quotePrice詢價：單價、手續費、庫存、錢包餘額夠不夠不會
purchase/create下單，扣運營錢包，回傳連結會
purchase/query查單（沒有回調，未發貨要輪詢）不會
purchase/applyComplaint發起投訴，需 1–6 張截圖不會
goods/detail、goods/list商品詳情、已代理的貨源清單不會
  • 簽章：HMAC-SHA256，時間誤差上限 ±300 秒，nonce 600 秒內不可重複。
  • 客戶端：在 source16688 資料夾，15 個離線測試通過。「下單」指令必須設金額上限且明確確認才會扣款；憑證只放本機 .env，不進對話、不進文件。
  • 前提：文件寫詢價限「已代理貨源」，實測是帳號成為代理後才能用。
  • 和獨角數卡的關係：獨角數卡的「站點對接」只認另一台獨角數卡，協定與 16688 不同，沒辦法直接接。後續要寫一層轉接，或付款後直接向 16688 下單、再把連結寫進卡密庫存。

資料來源：16688 開放 API 文件、獨角數卡站點對接說明、站點對接 API。

已知風險

收款受限：台灣與歐美客人付不了 16688 的店面。

16688 自己的店面只收支付寶和微信；獨角數卡沒有綠界、藍新。金流業者也可能拒絕轉售訂閱類商品，串接前要先問。

下一步

用約 ¥30–¥40（NT$135–180）小量購買，找出哪個賣家的連結「能啟動、期限真的是 18 個月」。

  1. 充值運營錢包約 ¥30–¥40（金錢操作，由帳號擁有者自己做）。
  2. 從評分表選 3–5 個賣家，每家買 1 份。用客戶端的 buy 指令，必須設「上限金額」且明確確認才會扣款。
  3. 拿到連結後 1 小時內，用乾淨的測試 Google 帳號啟動。記錄：能否啟動、是否要切換地區、方案名稱、到期日，並截圖。
  4. 故意測一次 16688 的投訴流程，看賣家多快處理，這決定我們能不能對客人承諾補發。
